# 军理背诵

手机端背诵专用站（无刷题 / 无模拟考），面向 2026-10-17 军事理论考试。

**在线：** https://xiezhihao891-arch.github.io/junli-beishu/

## 功能

- **今日背诵** — 根据「不会 / 模糊」与到期复习队列生成今日任务（Leitner 盒）
- **背诵卡** — 大字点击翻转；会 / 不会 / 模糊；章节筛选；洗牌；专注模式
- **时间轴默写** — 事件↔日期互测；按主题分组
- **挖空背诵** — 重点句挖空；揭示 / 自检；左右滑下一题
- **章节提纲** — 章→节→要点一行；点开展开全文

进度保存在本机 `localStorage`。可添加到主屏幕（PWA manifest）。

内容来自同一套军理讲义结构化数据，与刷题站分离。
